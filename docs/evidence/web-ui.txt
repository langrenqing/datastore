真实数据（2026-11-03）：
- XAU：5,184 根日线，来自新浪财经，最新 2026-11-03。
- GDELT：23,519 条关注事件，覆盖 2026-10-04 ~ 2026-11-01。为验证只抓取了最近 30 天中的 29 天；
  最后一天下载超时，运行记录如实保留为「部分成功」。

验证：
- `python -m pytest -q`：84 passed（离线；含 FastAPI TestClient 的 API、任务状态与 CLI 记录测试）。
- 浏览器操作：三个标签切换、价格 30/90/180/365/全部与自定义区间、事件 30 日与自定义区间、
  事件列表筛选/分页、采集表单模式切换均正常；浏览器控制台无错误。
- 手动采集：通过 Web API 触发价格任务，子进程执行、进度与摘要写入 collection_runs，页面轮询并
  在完成后刷新数据（run #4 成功）。
- 接口实测（本机，2.3 万事件）：/api/status ~0.25s；/api/prices?symbol=XAU&days=180 ~0.24s / 44KB；
  /api/events?days=30&limit=50 ~0.04s；/api/events/overlay?days=90 ~0.56s / 112KB。
